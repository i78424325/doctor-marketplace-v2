Ссылка для входа в админку

Тот, кому вы отправите ссылку, откроет админку сразу — без GitHub, логинов и паролей. Браузер запомнит вход.

  1. Создайте ключ на GitHub: доступ только к doctor-marketplace-v2, разрешение Contents: Read and write.
  2. Вставьте ключ ниже. Ссылка собирается прямо в этом браузере, ключ уходит только на GitHub — для проверки.
  3. Отправьте ссылку лично, например в Telegram.

Проверить вход

Ссылка — это ключ от админки: не публикуйте её. Если она ушла не туда, удалите ключ на GitHub — ссылка сразу перестанет работать, и можно сделать новую.
